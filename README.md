# Portfolio — Maxence

Site statique (un seul `index.html` + le dossier `media/`), hébergé avec GitHub Pages.

- **Voir le site** : `https://<ton-pseudo>.github.io/<nom-du-dépôt>/`
- **Modifier depuis le site** : petit `+` caché en haut à droite → mot de passe → jeton GitHub (voir le tutoriel).
- **Modifier depuis l'ordinateur** : change les fichiers, puis *Commit* et *Push* dans GitHub Desktop.

Règles à respecter :
- aucun fichier de plus de 100 Mo (limite GitHub) ;
- garder les noms de fichiers de `media/` exactement identiques (majuscules comprises) ;
- ne jamais écrire le jeton GitHub dans un fichier du dépôt.
